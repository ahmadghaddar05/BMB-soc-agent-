# Phase 3 — Explainable Correlation and Incident Decisions

Phase 3 makes incident correlation understandable from Incident Command without
adding a separate dashboard. It consumes the append-only workflow provenance
introduced in Phase 1 and the progressive-disclosure pattern introduced in
Phase 2.

## What analysts can now see

Every incident workspace contains a compact **Why were these alerts grouped?**
panel. It shows:

- whether the correlation created, updated, or matched an incident;
- the recorded model confidence, clearly labelled as a model score;
- the Hermes provider/model recorded for the decision;
- how many correlated alerts have correlation and final incident-decision
  records;
- identities, hosts, IPs, databases, and processes that visibly repeat across
  at least two returned alerts;
- a collapsed per-alert decision list for deeper review.

The shared-link summary is calculated from stored alert fields returned by the
incident API. It is not generated by the browser or model from unsupported
data.

## Backend contract

`GET /api/incidents/:id/journey` now returns:

- append-only incident-level workflow events;
- the incident correlation run identifier;
- the latest recorded `correlated` and `incident_decision` event for each linked
  alert;
- explicit coverage counts.

It does not embed raw logs. Missing decisions remain missing and are never
reconstructed.

## Decision boundary

Hermes proposes a related alert group. BMB then independently validates:

1. every cited alert ID;
2. shared entity relationships;
3. time-window proximity;
4. group overlap;
5. incident persistence.

The UI explains this boundary and reminds the analyst that correlation does not
prove compromise or authorize containment. Analysts retain responsibility for
incident confirmation, ownership, and response planning.

## Historical behavior

Incidents or alerts created before workflow provenance may show **Not
recorded**. Phase 3 does not invent historical evidence. New and replayed
correlation runs store alert-level outcomes that this panel can display.
